# Hiltop Plumbing Supplies

Trade-counter website for Hiltop Plumbing Supplies (Pty) Ltd, 3B Saligna Road, Merrivale, Howick.

Customers browse the counter list, build a quote slip on their phone, and send it on WhatsApp. There is no login, payment or order database.

Read [HANDOVER.md](HANDOVER.md) first. It says which facts are confirmed, which are placeholders, and which file holds each one.

```
npm install
npm run dev        # http://localhost:5173
npm test
npm run typecheck
npm run build      # static site in dist/client
```
